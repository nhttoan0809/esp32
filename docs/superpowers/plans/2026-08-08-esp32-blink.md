# ESP32 Blink LED Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Create and verify a minimal PlatformIO ESP32 Blink LED project in `blink/` that builds successfully, so the user can later upload it to their board.

**Architecture:** Standard PlatformIO project: `platformio.ini` (board `esp32dev`, Arduino framework, monitor 115200) + `src/main.cpp` with `setup()`/`loop()` blinking `LED_BUILTIN` every 1s. User builds via the PlatformIO IDE button in VS Code.

**Tech Stack:** PlatformIO Core 6.1.19 (CLI at `~/.platformio/penv/bin/pio`), platform `espressif32`, framework `arduino`, VS Code + PlatformIO IDE extension.

## Global Constraints

- Board: `esp32dev` (ESP32-WROOM-32 DevKit, 38-pin). No physical board yet — no upload step.
- Framework: `arduino`; API surface limited to `pinMode`, `digitalWrite`, `delay`, `LED_BUILTIN`.
- Monitor baud rate: `115200`.
- All commands run with `~/.platformio/penv/bin/pio` (bare `pio` is not on PATH).
- Working directory: `/Users/toannguyen/Documents/esp32-learning`.
- UI copy in README: Vietnamese.
- Project files live in `blink/`; spec and plans live under `docs/superpowers/`.
